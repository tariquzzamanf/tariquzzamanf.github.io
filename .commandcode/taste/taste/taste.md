# Taste
- Maintains the CV in two parallel representations and expects edits mirrored across all of them: the LaTeX source (`files/cv/tariq.tex`) plus its recompiled PDF, and the web CV page (`content/cv.html` + regenerated site). When adding/updating CV entries, apply them to both the LaTeX and web versions rather than one. Confidence: 0.7
- Wants the CV PDF set in the same body font as the website so the two representations look typographically consistent ("can we use the same font on the cv just like the website?"). Match the font the site actually renders in, not just its preferred stack. Confidence: 0.7
- Prefers genuine typeface cuts over synthesized ones for weights — real bold via the variable weight axis rather than FakeSlant/fake-bold tricks. Confidence: 0.6
- Does not want italics used to de-emphasize CV text: rejected the real Literata Italic as "cartoonish" and "not even italic", and asked for the upright main font at a lighter weight instead. Degree/date lines and publication venue lines should read lighter and upright, not slanted. Confidence: 0.8
- Wants notable achievements recorded in the dedicated "Awards & Achievements" section, not only as inline details under an education/career entry, listed reverse-chronologically. Confidence: 0.7
- Wants publications grouped and ordered Conference → Journal → Workshop → Submission, consistently across both the website and the LaTeX CV (and any guide documenting the order); numbering is per-category (C/J/W/S), not positional, so it stays fixed when groups are reordered. Confidence: 0.7
- Dislikes redundant qualifier labels in displayed content: rejects status annotations like "(accepted)" next to a venue name because the venue ("Findings of ACL 2026") already implies acceptance. Strip labels that add no information, and prefer relying on existing structure (group headings, venue names) instead of repeating the same fact. Confidence: 0.65
- Uses "Thesis" and "Supervisor" as the CV labels, not "Research"/"Advisor" — expects these corrected wherever they appear (e.g. under the M.Sc. entry). Confidence: 0.7
- Prefers CV detail lines plain and unadorned: no bold anywhere and no trailing colon in the label (e.g. "Best Student Award (2018)" rather than "**Best Student Award:** 2018", and "Talent Pool Scholarship (17th in Chattogram Board)" with the rank not bolded). Styling should be consistent across bullets. Confidence: 0.8
- Prefers restrained, understated emphasis in typography overall, not just in detail lines: heavy bold reads as too strong ("bold fonts are a bit too bold... it should be more subtile"). Favor subtle bold weights that keep a real contrast with body text without a heavy punch. Confidence: 0.7
- Judges a change against the previous/prior version of the document as the reference point ("check my previous version"), expecting the new styling to land close to that established look rather than being visibly heavier or different. Confidence: 0.6
