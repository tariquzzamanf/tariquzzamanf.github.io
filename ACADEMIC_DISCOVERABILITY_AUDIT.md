# Academic discoverability audit

## Implemented

- Added stable static publication pages at `/publications/<slug>/` for every record in `content/publications.json`.
- Expanded each paper page into a readable article hub with the verified title, complete ordered author list, venue, status, topics, a plain-language summary based on the paper abstract, the full abstract, a representative extracted figure with caption, direct external PDF download, external paper/code/dataset/video links, and a copyable citation block.
- Added extracted figure assets under `files/papers/` from the public arXiv and ACL Anthology records used for the pages; paper PDF buttons point directly to authoritative external PDF URLs and no paper PDFs are stored in this repository.
- Added a browser-enhanced “Copy citation” control that falls back to keyboard-selectable citation text when clipboard access is unavailable.
- Kept publication metadata data-driven: titles, ordered authors, years, venues, statuses, topics, abstracts, summaries, figures, and resource URLs come from `content/publications.json`.
- Kept self-referencing canonical URLs, index/follow robots metadata, paper-specific titles, descriptions, Open Graph, Twitter metadata, Highwire citation tags, and `ScholarlyArticle` JSON-LD.
- Added the verified arXiv identifiers and direct absolute PDF URLs to scholarly metadata. DOI, pages, issue, and ISSN fields remain optional and are emitted only when verified source data is added; the official ACL DOI, pages, and verified BibTeX are included for the Findings paper, and verified BibTeX entries are included in every paper page.
- Expanded the XML sitemap to include all public pages and publication routes.
- Updated `robots.txt` to allow normal crawling and explicitly allow `OAI-SearchBot`, `Claude-SearchBot`, `Claude-User`, `Googlebot`, and `Bingbot`.
- Added a concise generated `llms.txt` index as a supplemental route map.

## Existing architecture

This is a plain static site generated by `scripts/build.py` with Python's standard library. Page copy lives in `content/*.html`; publication records live in `content/publications.json`; the builder writes root HTML, nested publication `index.html` files, `sitemap.xml`, `robots.txt`, and `llms.txt`. GitHub Pages serves the repository root from `main` with `.nojekyll`.

## Crawler configuration

The public site allows all user agents and explicitly permits OpenAI's search crawler (`OAI-SearchBot`), Anthropic retrieval/search crawlers (`Claude-SearchBot` and `Claude-User`), and conventional crawlers (`Googlebot` and `Bingbot`). Search/retrieval access is independent from model-training crawler policy; no unsupported `CodexBot` rule is present. Allowing a crawler does not guarantee indexing or retrieval.
