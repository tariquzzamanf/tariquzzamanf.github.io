# Md. Tariquzzaman — Academic Website

Source for [tariquzzamanf.github.io](https://tariquzzamanf.github.io).

The site is built with Jekyll. Primary content lives in `_pages/`, shared research metadata lives in `_data/research.yml`, and public assets live in `images/` and `files/`.

Build locally with:

```bash
bundle exec jekyll build
```
